# conferenza-life-js

Le slide della conferenza "Life, il gioco della vita" di Gian Marco Todesco, in
HTML/JavaScript: animazioni interattive, dagli automi cellulari alla porta AND fatta di
glider fino a Life simulato da Life (hashlife).

    python serve.py        # poi http://127.0.0.1:8766/

PageDown/PageUp cambiano slide, le frecce laterali i passi, F lo schermo intero. I tasti
di ogni slide sono in `SLIDES.md`; lo stato del lavoro in `STATO-PROGETTO.md`.
